# festival_platform


축제 통합 관리 플랫폼 개발 명세서
1. 프로젝트 개요
시스템명: SaaS 기반 멀티 테넌트(Multi-tenant) 축제 관리 시스템

핵심 컨셉: 하나의 시스템 엔진으로 매년 발생하는 수십 개의 축제를 독립적으로 개설하고, 각 축제별 전용 관리자에게 독립된 데이터 환경을 제공하는 SaaS 모델.

주요 대상: 축제 최고관리자(SaaS 운영자), 행사별 총괄관리자(주최사), 현장 스태프(주차/체크인/상점), 방문객.

2. 기술 환경 (Tech Stack)
기본 엔진: 그누보드 5 (Gnuboard 5.5+) 기반 커스텀

언어 및 서버: PHP 8.0 이상, Apache/Nginx

데이터베이스: MariaDB 10.3 (MySQL 호환)

프론트엔드: HTML5, CSS3, jQuery (그누보드 관리자 UI 최적화)

데이터 격리 방식: 단일 DB 내 fs_id(Festival ID) 컬럼 기반 논리적 격리
